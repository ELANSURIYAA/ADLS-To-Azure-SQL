1. Business Understanding

Business Domain:
Customer Relationship Management (CRM) and Research Subscription Data Integration

Business Entities:
- CRM Client (Source: DS_SOURCE_CRM_CLIENT)
- Research Subscription (Source: DS_SOURCE_RESEARCH_SUBSCRIPTION)
- Target Client (Sink: DS_TARGET_CLIENT)
- Error Log (Sink: DS_ERROR_LOG)

Business Objective of the Pipeline:
To consolidate and enrich client data from CRM and research subscription systems, derive business classification/status fields, validate data quality and business rules, and route valid/enriched records to the target client table while logging invalid/error records for audit and remediation.

Key Business Transformations:
- Data enrichment via left join between CRM Client and Research Subscription on name
- Multiple derived/calculated fields (e.g., ClientStatus, RelationshipType, Contract dates)
- Business rule validations (enum checks, null checks, date logic)
- Data quality error aggregation and error routing
- Conditional split for valid vs. error records

3. Detailed Functional Test Cases

Test Case ID: FTC_01
Title: Successful Enrichment and Field Derivation for Valid Client
Business Scenario: A CRM client record with all required fields and a matching research subscription is processed.
Input Condition: CRMClientSource.ClientFullName matches ResearchSubscriptionSource.SubscriberName, all fields are valid and within allowed values.
Expected Behavior: Record is enriched, all derived fields are populated correctly, ValidationErrors is empty, and record is routed to TargetClient.

Test Case ID: FTC_02
Title: Error Routing for Null or Empty ClientName
Business Scenario: A CRM client record has ClientFullName as null or only whitespace.
Input Condition: CRMClientSource.ClientFullName is null or consists only of spaces.
Expected Behavior: ValidationErrors contains 'ClientName cannot be null;', record is routed to Error sink with details.

Test Case ID: FTC_03
Title: Enum Validation for IndustrySector Field
Business Scenario: IndustryCode is not one of the allowed values (Technology, Healthcare, Finance, Manufacturing, Retail, Energy, Other).
Input Condition: CRMClientSource.IndustryCode = 'Agriculture'
Expected Behavior: ValidationErrors contains 'IndustrySector invalid;', record is routed to Error sink.

Test Case ID: FTC_04
Title: Enum Validation for RevenueRange Field
Business Scenario: AnnualRevenueRange is not in the allowed set ('<1M', '1M-10M', '10M-100M', '100M-1B', '>1B', 'Unknown').
Input Condition: CRMClientSource.AnnualRevenueRange = '5B-10B'
Expected Behavior: ValidationErrors contains 'RevenueRange invalid;', record is routed to Error sink.

Test Case ID: FTC_05
Title: Enum Validation for EmployeeCountRange Field
Business Scenario: EmployeeRange is not in the allowed set ('1-10', '11-50', '51-200', '201-1000', '1001-5000', '5000+', 'Unknown').
Input Condition: CRMClientSource.EmployeeRange = '0-1'
Expected Behavior: ValidationErrors contains 'EmployeeCountRange invalid;', record is routed to Error sink.

Test Case ID: FTC_06
Title: Enum Validation for RelationshipType Field
Business Scenario: SubscriptionType is not in the allowed set ('Premium', 'Standard', 'Basic', 'Trial').
Input Condition: ResearchSubscriptionSource.SubscriptionType = 'Enterprise'
Expected Behavior: ValidationErrors contains 'RelationshipType invalid;', record is routed to Error sink.

Test Case ID: FTC_07
Title: Null Check for ContractStartDate
Business Scenario: ContractStart is null.
Input Condition: CRMClientSource.ContractStart is null.
Expected Behavior: ValidationErrors contains 'ContractStartDate cannot be null;', record is routed to Error sink.

Test Case ID: FTC_08
Title: Contract End Date Validation
Business Scenario: ContractEnd is before or equal to ContractStart.
Input Condition: CRMClientSource.ContractEnd <= CRMClientSource.ContractStart
Expected Behavior: ValidationErrors contains 'ContractEndDate must be > ContractStartDate;', record is routed to Error sink.

Test Case ID: FTC_09
Title: Derived ClientStatus Logic
Business Scenario: StatusFlag is 'A' or not 'A'.
Input Condition: CRMClientSource.StatusFlag = 'A' or another value.
Expected Behavior: If 'A', ClientStatus is 'Active'; else, 'Inactive'.

Test Case ID: FTC_10
Title: Multiple Validation Errors Aggregation
Business Scenario: Multiple fields are invalid in the same record (e.g., ClientName is null, IndustrySector invalid, ContractStartDate null).
Input Condition: CRMClientSource.ClientFullName is null, IndustryCode = 'Agriculture', ContractStart is null.
Expected Behavior: ValidationErrors aggregates all applicable messages; record is routed to Error sink.
